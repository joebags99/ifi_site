# Images Needed

Add the following images to this directory:

## Required Images
- `logo.png` - Main Icing for Izaac logo (heart cake logo from existing site)
- `favicon.png` - Small icon for browser tab (32x32 or 64x64)

## Homepage Images
- `cheesecake.jpg` - Featured cheesecake photo
- `cookies.jpg` - Featured cookies photo
- `cupcakes.jpg` - Featured cupcakes photo
- `family-photo.jpg` - Grayce and family photo

## Optional Images
- `hero-pattern.png` - Subtle background pattern for hero section
- `placeholder-product.jpg` - Default image for missing product photos

## Recommended Dimensions
- **Featured Products**: 800x600px (4:3 ratio)
- **Hero/Banner**: 1920x1080px (16:9 ratio)
- **Logo**: Transparent PNG, at least 400x400px
- **Family Photo**: 800x800px (square or similar)

## Image Guidelines
- Use high-quality images (not pixelated)
- Ensure good lighting and professional look
- Match the pink/gold/white aesthetic
- Compress for web (use tools like TinyPNG)
- Use JPG for photos, PNG for logos/graphics

## Where to Get Images
1. Use photos from the existing Squarespace site
2. Take new professional photos of products
3. Use Canva for graphics and patterns
4. Hire a photographer for professional shots
